Pipeline Details
daily-macro

Scrapes HKEJ instant news, normalises articles into SQLite, and runs a multi-stage LangGraph pipeline to produce categorised analyst digests with entity extraction, attention tiers, and incremental caching.

🕐07:00 UTC + 20:30 UTC 📰HKEJ instantnews 🤖Llama 4 Scout → Qwen 3 32B → Llama 3.1 8B 📧Gmail + GitHub Pages
Pipeline: LangGraph state graph · attention routing (high/medium/light) · category batching · token budget pacing · rate-limit governor · JSON repair retries · fallback model chain · static site builder
daily-market

Fetches live OHLCV snapshots for 16 macro assets (indices, commodities, FX, crypto) via yfinance, persists history in SQLite, and emails a bilingual EN/ZH % change summary twice daily.

🕐06:59 HKT + 18:00 HKT 📈yfinance · 16 assets ⚙️No LLM — signals engine planned 📧Bilingual Gmail tables
Assets: HSI · SSE · SPX · NDX · DJI · Nikkei · KOSPI · Stoxx50 · FTSE · Gold · WTI · USD/CNH · GBP/HKD · USD/JPY · DXY · BTC  ·  partial-failure tolerant · latest-available data timestamping
youtube-intake

Monitors finance YouTube channels for new videos and completed livestreams, archives transcripts, runs Groq LLM analysis per video, and emails a compact analyst digest only when new content appears.

🕐Every 6h + hourly retry ▶️YouTube RSS · yt-dlp · Whisper STT 🤖Llama 4 Scout → Llama 3.3 70B 📧Per-video analyst Gmail digest
Pipeline: RSS discovery → transcript fetch → Groq analysis → retry manifest → multi-key rotation · chunked transcript analysis · Whisper STT fallback (≤60 min) · run-level synthesis
marine‑traffic‑monitor

Monitors the Strait of Hormuz every 15 minutes via Playwright + OpenCV, gates LLM calls behind a count-threshold, produces dual-analyst evidence (visual + context), and routes through a deterministic policy engine to manage alert escalation.

🕐Every 15 min (daemon) 🚢MarineTraffic · Google News · GDELT 🤖Scout (visual) + Llama 3.3 70B (context) 🚨Alert emails + daily digest
Pipeline: Playwright screenshot → OpenCV polygon ship-count → dual-LLM evidence (no verdicts) → 7-rule policy engine → state machine (NORMAL→WATCH→ESCALATED→CRITICAL) · consensus mode (6-model voting) · JSONL audit trail
